# Floating Launcher

一个仿 Windows 11 风格的浮动应用启动器。从屏幕边缘滑入的应用面板 + 文件面板，支持快捷搜索、拖拽移动、Mica 材质。

## ✨ 功能

### 软件面板（左侧）
- 从屏幕左边缘滑入
- 显示桌面快捷方式和 `.exe` 应用
- 支持搜索（拼音首字母 + 全拼）
- 可切换到「全部应用」（开始菜单 + UWP 商店应用）
- 双击打开，图标可切换：真实 / 遮罩 / 重绘

### 文件面板（右侧）
- 从屏幕右边缘滑入
- 显示桌面上的文件夹和文件
- 拖拽移动文件到其他文件夹
- 重命名 / 移动到回收站
- 新建文件夹 / 文件

### 系统集成
- **全局快捷键**：`Alt+1` 打开软件面板 / `Alt+2` 打开文件面板 / `Esc` 关闭
- **托盘菜单**：打开面板、刷新、切换图标风格、设置、开机自启、退出
- **系统材质**：Win11 Mica / Win10 Acrylic
- **游戏全屏保护**：独占全屏游戏运行时（如 CS2、原神）不弹面板
- **深色 / 浅色 / 跟随系统**：三种主题

### 设置
- 主题颜色
- 图标风格 / 大小
- 字体大小 / 样式 / 上传自定义字体
- Mica 强度（0-100）
- 面板透明度（0-100，只影响背景）
- 开机自启
- 游戏全屏时暂停

## 🛠 技术栈

- **前端**：原生 JS + Vite
- **后端**：Rust + Tauri 2
- **UI**：纯 HTML/CSS，无框架

## 📦 依赖要求

- Node.js ≥ 18
- Rust ≥ 1.77
- Windows 10 1809+ / Windows 11

```bash
# 安装依赖
npm install

# 开发模式（热重载）

# 打包发布（生成 NSIS 安装包）
